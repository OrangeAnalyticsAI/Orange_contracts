📱 Install Mobile App

Install Orange Contract as a standalone applet on your Android phone or computer for instant access and offline usability.

To install manually: Tap your browser's menu (three dots) and select "Add to Home screen" or "Install app".

🧠 Gemini AI Integration

Supply a Gemini API Key to intelligently parse any booking email (such as airport parking, hotels, train tickets, flights, or meals). Settings are stored in your secure Supabase database and sync automatically to all devices.

How to get a Free Gemini API Key
  1. Go to aistudio.google.com
  2. Click Get API Key and sign in with any Google Account
  3. Click Create API Key
  4. Copy the generated key and paste it below

📍 Locations

Define the locations you travel to. These will appear as a dropdown when adding expenses.

Google / Gmail Integration

To let the app search your Gmail for easyJet booking confirmations, you need a Google OAuth Client ID. This is a one-time setup.

How to get a Google Client ID
  1. Go to console.cloud.google.com
  2. Create a new project (e.g. OrangeContract)
  3. Go to APIs & Services → Enable APIs and enable the Gmail API
  4. Go to APIs & Services → Credentials → Create Credentials → OAuth client ID
  5. Application type: Web application
  6. Add http://localhost:8000 as an Authorised JavaScript origin
  7. Copy the Client ID (ends in .apps.googleusercontent.com) and paste below

Database Connection

Connect to Supabase for persistent storage across devices. Without this, data is stored locally in your browser only.

🔐 Credential Backup & Restore

Securely backup your API keys and credentials to a file, or restore from a previous backup. This is useful when switching browsers or devices. The backup file is encrypted.
